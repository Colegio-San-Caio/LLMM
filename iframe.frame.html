Macro Logic - iframe.frame evaluation: 
INPUT:  <frame src="X">  (HTML 3.2 - deprecated 1999)
        <frameset cols="25%,75%">

OUTPUT: <div style="display:flex">
          <iframe src="X" style="flex:1"></iframe>
        </div>

JS ACCESS:
  OLD: window.frames['main']  or  frame.iframe (WRONG)
  NEW: document.getElementById('myIframe').contentWindow
       or window.frames[0] or iframe.contentDocument

EVAL: frame → iframe
      frameset → div + flex
      noresize, frameborder → CSS border:0
